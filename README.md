# Music-Player-using-tkinter-
Music Player (Python)

This is a simple desktop music player built using Python with CustomTkinter for the GUI and Pygame for audio playback. It allows users to play, pause, and navigate through a list of songs with a clean interface.

Features
Play and pause music
Next and previous track controls
Display album cover and song name
Volume control slider
Seek bar to navigate within a song
Dynamic play/pause button icons
Technologies Used
Python
CustomTkinter (GUI)
Pygame (audio playback)
PIL (image handling)
How It Works

The player loads songs from a predefined list and plays them using Pygame. The interface updates in real time using threading to manage the progress bar and playback state.

Folder Structure
music/ contains audio files
img/ contains album covers and control icons
main Python file runs the application
Usage

Run the Python file and use the buttons to control playback. The slider allows seeking within the track and adjusting volume.
